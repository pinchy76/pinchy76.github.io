Oracle Primavera P6 XER Cleansing Tool

My tool for cleaning junk data from Oracle Primavera P6 XER import files.

If you regularly import schedules into Primavera P6 you'll know that a lot of junk data can get pulled through into your database.
"Junk" data can pollute your database, slowing it down and making it harder to navigate.
A bug in database field called POBS in older versions of Primavera caused a flood of junk data to fill XERs.
More recently the RISKTYPES field also churns out junk. JUNK

This utility will clean junk data tables like POBS and RISKTYPES.

It also gives the option to remove other fields from the import file.

There is also the option to tag data. This is useful if you import from multiple sources (eg. subcontractor schedules) because it allows you to add a tag so you can see whose calendars, activity codes etc. belong to which contractor.
