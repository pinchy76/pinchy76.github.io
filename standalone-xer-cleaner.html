ℹ️ How It Works

This tool is completely secure and private:

  • ✅ All processing happens locally in your browser
  • ✅ Your XER files never leave your computer
  • ✅ No data is sent to any server or stored anywhere
  • ✅ Works offline once the page is loaded

What gets cleaned:

  • 🗑️ POBS and RISKTYPES tables (always removed for performance)
  • 🏷️ Optional tagging or removal of UDFs, Activity Codes, Calendars, Resources, and Roles
  • 📦 Non-essential tables like documents, locations, and memos
  • ⚡ File size optimization for faster imports

Why clean XER files:

  • 🚀 Faster database imports
  • 🛡️ Prevent database pollution from external data
  • 🔍 Make imported data easily identifiable
  • 💾 Reduce storage requirements
